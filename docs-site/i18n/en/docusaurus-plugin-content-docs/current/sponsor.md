# Sponsor ZzClawTerm

Thank you for supporting ZzClawTerm. Sponsorship helps with ongoing feature development, compatibility testing, documentation, release packaging, and infrastructure costs.

Sponsorship is completely optional and does not affect open-source access to ZzClawTerm. Feedback, bug reports, documentation improvements, code contributions, and sharing the project are also meaningful ways to help.

# AI / MCP 终端执行

集成的 NyaTerm Agent、Codex 和 Claude Code 统一使用现有后台执行设置。
关闭时向目标会话的当前 PTY 发送命令；开启时使用 SSH exec 或独立本地进程。
外部 MCP 固定选择当前 PTY。运行期间修改设置不改变已启动任务或集成 AI generation 的策略。

`terminal_output_lines` 控制前台 AI 命令块的输出行数；0 隐藏整个块，不改变执行方式。
最终解析为 `SendOnly` 的会话直接发送命令，保留正常回显，立即返回无法捕获输出与退出码的说明。
`Disabled` 拒绝执行。后台模式只支持 SSH 和 LocalPty，不在失败后切换执行路径。

## 所有权与边界

- desktop capability 的 `TerminalExecutionState` 唯一拥有任务、目标占用、捕获、序号及回复。
  不同目标可并行，同一目标冲突返回 `target_busy`。
- 内置 Agent 经过共享 capability 权限和风险检查；集成 CLI 通过临时 MCP generation
  读取运行时策略，外部 MCP 使用前台默认值。策略识别不依赖当前可见 AI 面板。
- `nyaterm-core::agent_capture` 保留命令包装构造；流解析、跨分片标记处理和捕获限额
  位于 `nyaterm-terminal::agent_capture`。transport 负责原有会话 I/O 和后台进程。
- RPC 请求 ID 与随机内部执行标识分离。复用 RPC ID 或迟到的后台完成事件不能结束新任务。

## 输出顺序与展示

前台执行先在 transport 原始事件队列加入 `OutputBoundary`，再写入包装命令。
桥接 worker 将边界之前的全部输出顺序提交或转交 UI；UI 消费边界时才开始捕获并绘制开始块。
这样可保留已排队输出，且不会让它排在命令块之后或被新捕获误吞。

包装输入、开始/结束标记和包装提示符由捕获层隐藏。捕获期间转发必要的终端查询，
使 ConPTY / Shell 的光标和终端属性握手可以完成，其余捕获输出不会直接修改屏幕。
输出最多保留 8 MiB；超限继续扫描结束标记，返回 `source_truncated`。

开始与完成使用类型化事件，包含内部任务标识、目标、来源、序号、命令和结果。
显示内容先清理工具控制序列，再添加应用样式。显示截断不影响 AI / MCP 可读取的捕获结果。
合成内容经 frame pipeline 的 `SyntheticOutput` 命令顺序修改屏幕并发布快照，
不进入传输检测、凭据识别、输出观察或录制；正常源输出继续使用原有通道。

## 收尾

完成、失败、超时、取消、断开、客户端离线及 generation 失效统一从共享状态移除任务，
回复一次并释放目标。迟到事件按内部执行标识忽略。前台取消仅停止等待和捕获，
不发送 Ctrl+C，也不表示远端进程已终止。普通后续输出恢复正常路由；
仅保留已取消任务的短标记过滤器，直到其结束标记到达或目标会话关闭。

捕获期间，逻辑输入、原始输入、敏感输入、粘贴和广播写入都在目标级别被拒绝。
其他目标继续使用。后台任务不占用用户输入，但仍占用自动执行目标，防止并发自动任务互相干扰。

## 兼容性与验证

不新增持久化字段，不改变 MCP 工具、参数、返回结构或设置默认值。
`inserted_to_terminal` 仅在 PTY 实际写入成功后记录，后台成功不会置为 true。

测试覆盖策略隔离、序号、占用、跨分片/Unicode/伪标记、限额、终端查询、展示与控制序列清理、
输出队列边界、取消/超时/断开及迟到事件。Windows PTY 集成测试覆盖 CMD、PowerShell、
隐藏目标、四类调用来源的共享入口、后台不显示和 SendOnly。
这些测试不替代真实 Codex / Claude Code CLI 会话、SSH 容器或嵌套 Shell 的人工端到端验收。

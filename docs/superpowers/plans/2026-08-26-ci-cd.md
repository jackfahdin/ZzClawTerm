# CI/CD 建设 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 主仓落地三 workflow——ci.yml 快门禁（含 Continuous Build 出包）、perf.yml nightly 门控、release.yml tag 发布。

**架构：** ZzSshCore 不单建 CI，主仓 CI 递归拉子模块统一覆盖；三 workflow 独立触发、独立重跑；打包复用现有三个脚本（版本号参数化后供 CI 注入）。

**技术栈：** GitHub Actions、jurplel/install-qt-action@v4（Qt 6.11.1）、docker（ubuntu runner 内置）、gh CLI（runner 内置）、actionlint（本地预检）。

**规格：** `docs/superpowers/specs/2026-08-26-ci-cd-design.md`（已批准）

**已核实的关键事实（实现者不必重新调查）：**
- 三平台 preset 已齐全：`linux-gcc-release` / `windows-msvc2022-release` / `macos-clang-release`（主仓 CMakePresets.json，均取 `$env{QT_ROOT}` 作 CMAKE_PREFIX_PATH）。
- 库 preset：`linux-release`（third_party/ZzSshCore/CMakePresets.json，Ninja，**不读 QT_ROOT**——靠 install-qt-action 设置的 `Qt6_DIR` 环境变量即可被 find_package 命中）。
- 主仓 Qt 组件：Core Gui Widgets Network Test Xml **Multimedia**（qtmultimedia 需在 install-qt-action 显式装；Xml 在 qtbase 内）。库只需 qtbase。
- install-qt-action 设置环境变量 `Qt6_DIR`（形如 `.../gcc_64/lib/cmake/Qt6`）；主仓所需 `QT_ROOT` 由 `${Qt6_DIR%/lib/cmake/Qt6}` 推出。
- 打包脚本现状：linux（linuxdeploy + plugin-qt 需在 PATH；Ubuntu 24.04+ 缺 libtiff.so.5 → **用 ubuntu-22.04 打包**）、windows（windeployqt + Compress-Archive，无 NSIS）、macos（macdeployqt -dmg；**vendored OpenSSL bundle 无 macOS 产物，需 brew openssl@3 回退**，且该脚本从未实机验证——macOS 打包是已知风险任务）。
- 三个打包脚本产物名硬编码 `ZzClawTerm-v0.1-*`，需版本号参数化（任务 3）。
- `run-integration-tests.sh:103` 固定 `-L 'integration|perf'`，需加标签开关（任务 1）。
- 主仓单测 45 程序基线（含 LABELS=perf 的 4 个：ZzLogEnginePerfTest、ZzColdStoragePerfTest、ZzCredentialPerfTest、tests/perf 其一；ZzColdStoragePerfTest 已知偶红复跑绿）；库单测 18 程序、docker 集成 integration 12 项 + perf 若干。
- ubuntu runner 需 `apt install xvfb x11-utils`（集成脚本的 Xvfb/xdpyinfo）；docker 已内置。
- **push 需用户逐项确认**（CI 只有推上去才能真跑——每个任务的"推送"步骤由控制者向用户确认后执行；首跑失败在推送分支上迭代修复属同一任务范畴）。
- commit：Conventional Commits 前缀 + 中文首行 + 空行 + 中文详述。

- [ ] **步骤 2：编写 ci.yml（主仓，先不含打包 job）**

创建 `.github/workflows/ci.yml`，完整内容：

```yaml
name: ci

on:
  push:
    branches: [master]
  pull_request:
    branches: [master]

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build-test:
    name: ${{ matrix.os }} 构建+单测
    strategy:
      fail-fast: false
      matrix:
        include:
          - { os: ubuntu-24.04, preset: linux-gcc-release, qt-arch: gcc_64 }
          - { os: windows-2022, preset: windows-msvc2022-release, qt-arch: win64_msvc2022_64 }
          - { os: macos-14, preset: macos-clang-release, qt-arch: clang_64 }
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: 安装 Qt 6.11.1
        uses: jurplel/install-qt-action@v4
        with:
          version: '6.11.1'
          arch: ${{ matrix.qt-arch }}
          modules: 'qtmultimedia'

      - name: 导出 QT_ROOT（由 Qt6_DIR 推前缀）
        shell: bash
        run: echo "QT_ROOT=${Qt6_DIR%/lib/cmake/Qt6}" >> "$GITHUB_ENV"

      - name: Linux 测试依赖（offscreen GUI）
        if: runner.os == 'Linux'
        run: |
          sudo apt-get update
          sudo apt-get install -y libgl1-mesa-dev libxkbcommon-dev libdbus-1-dev

      - name: macOS OpenSSL 回退（vendored bundle 无 macOS 产物）
        if: runner.os == 'macOS'
        run: |
          brew install openssl@3
          echo "OPENSSL_ROOT_DIR=$(brew --prefix openssl@3)" >> "$GITHUB_ENV"

      - name: 配置与构建
        shell: bash
        run: |
          cmake --preset ${{ matrix.preset }}
          cmake --build --preset ${{ matrix.preset }}

      - name: 主仓单测（45 程序基线）
        shell: bash
        env:
          QT_QPA_PLATFORM: offscreen
        run: ctest --preset ${{ matrix.preset }}

  zzsshcore:
    name: ZzSshCore 单测 + docker 集成
    runs-on: ubuntu-24.04
    steps:
      - uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: 安装 Qt 6.11.1（qtbase 即可）
        uses: jurplel/install-qt-action@v4
        with:
          version: '6.11.1'
          arch: gcc_64

      - name: 集成测试依赖（Xvfb / xdpyinfo）
        run: |
          sudo apt-get update
          sudo apt-get install -y xvfb x11-utils

      - name: 库构建 + 单测（18 程序）
        working-directory: third_party/ZzSshCore
        run: |
          cmake --preset linux-release
          cmake --build --preset linux-release
          ctest --test-dir build/linux-release -L unit --output-on-failure

      - name: docker 集成（integration 标签，12 项）
        working-directory: third_party/ZzSshCore
        env:
          ZZSSH_IT_LABELS: integration
        run: tests/integration/docker/run-integration-tests.sh build/linux-release
```

- [ ] **步骤 1：三个打包脚本版本号参数化**

`scripts/package-linux.sh`（产物命名处）：

```bash
# 版本号：默认 v0.1（手工用法不变）；CI 经 VERSION 环境变量注入
VERSION="${VERSION:-v0.1}"
```

产物行改为（文件名用 ${VERSION}）：

```bash
# 原：APPIMAGE 输出到 dist/ZzClawTerm-v0.1-linux-x86_64.AppImage（以脚本内实际行为准，替换硬编码 v0.1）
```

实现注意：通读脚本找到所有 `v0.1` 硬编码点（产物名/AppDir 内 desktop 不算）替换为 `${VERSION}`；`package-macos.sh` 同法（`ZzClawTerm-v0.1-macos.dmg` → `ZzClawTerm-${VERSION}-macos.dmg`）；`package-windows.ps1` 加 param：

```powershell
param(
    [string]$QtRoot = $env:QT_ROOT,
    [string]$Version = $(if ($env:VERSION) { $env:VERSION } else { "v0.1" })
)
```

`Compress-Archive` 目标改为 `"$root/dist/ZzClawTerm-$Version-windows-x64.zip"`。

验证（本机 Linux）：`VERSION=ci-test QT_ROOT=<本地Qt前缀> bash scripts/package-linux.sh` 产出 `dist/ZzClawTerm-ci-test-linux-x86_64.AppImage`；不带 VERSION 再跑一次确认默认产物名不变（手工用法不破坏）。Windows/macOS 脚本只能语法自检（bash -n / pwsh -NoProfile -Command 解析），实机验证靠 CI 首跑。

- [ ] **步骤 2：ci.yml 追加 Continuous Build 打包 job**

在 `zzsshcore` job 之后追加：

```yaml
  package:
    name: ${{ matrix.kind }} 持续构建出包
    needs: [build-test, zzsshcore]
    if: github.event_name == 'push' && github.ref == 'refs/heads/master'
    permissions:
      contents: write
    concurrency:
      group: continuous-build
      cancel-in-progress: false
    strategy:
      fail-fast: false
      matrix:
        include:
          - { os: ubuntu-22.04, kind: linux }   # 22.04 自带 libtiff5（打包脚本既有约束）
          - { os: windows-2022, kind: windows }
          - { os: macos-14, kind: macos }
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: 安装 Qt 6.11.1
        uses: jurplel/install-qt-action@v4
        with:
          version: '6.11.1'
          arch: ${{ matrix.qt-arch }}
          modules: 'qtmultimedia'

      - name: 导出 QT_ROOT
        shell: bash
        run: echo "QT_ROOT=${Qt6_DIR%/lib/cmake/Qt6}" >> "$GITHUB_ENV"

      - name: 矩阵补充字段（qt-arch）
        shell: bash
        run: true   # qt-arch 在 include 中按平台给出：linux=gcc_64、windows=win64_msvc2022_64、macos=clang_64

      - name: Linux 打包依赖（linuxdeploy + plugin-qt）
        if: matrix.kind == 'linux'
        run: |
          sudo apt-get update && sudo apt-get install -y libfuse2
          wget -q https://github.com/linuxdeploy/linuxdeploy/releases/download/continuous/linuxdeploy-x86_64.AppImage
          wget -q https://github.com/linuxdeploy/linuxdeploy-plugin-qt/releases/download/continuous/linuxdeploy-plugin-qt-x86_64.AppImage
          chmod +x linuxdeploy-*.AppImage
          echo "$PWD" >> "$GITHUB_PATH"

      - name: macOS OpenSSL 回退
        if: matrix.kind == 'macos'
        run: |
          brew install openssl@3
          echo "OPENSSL_ROOT_DIR=$(brew --prefix openssl@3)" >> "$GITHUB_ENV"

      - name: 打包
        shell: bash
        env:
          VERSION: continuous-${{ github.sha }}
        run: |
          case "${{ matrix.kind }}" in
            linux)   bash scripts/package-linux.sh ;;
            macos)   bash scripts/package-macos.sh ;;
            windows) pwsh scripts/package-windows.ps1 ;;
          esac

      - name: 更新 continuous-build 预发布
        shell: bash
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          set -e
          if ! gh release view continuous-build >/dev/null 2>&1; then
            gh release create continuous-build --prerelease \
              --title "持续构建（Continuous Build）" \
              --notes "master 每次 push 全绿后自动更新的验证包。"
          fi
          for f in dist/ZzClawTerm-continuous-*; do
            gh release delete-asset continuous-build "$(basename "$f")" -y 2>/dev/null || true
            gh release upload continuous-build "$f" --clobber
          done
          SHORT_SHA="${GITHUB_SHA::8}"
          gh release edit continuous-build \
            --notes "commit ${GITHUB_SHA}（${SHORT_SHA}）· $(date -u +'%Y-%m-%d %H:%M UTC') · 触发：${{ github.event_name }}"
```

注意：矩阵 include 需补 `qt-arch` 字段（linux=gcc_64、windows=win64_msvc2022_64、macos=clang_64，与 build-test 一致），上面"矩阵补充字段"步骤是占位提醒——落地时直接写进 include，不要留这个空步骤。

```yaml
          brew install openssl@3
          echo "OPENSSL_ROOT_DIR=$(brew --prefix openssl@3)" >> "$GITHUB_ENV"

      - name: 打包（版本号取 tag）
        shell: bash
        env:
          VERSION: ${{ github.ref_name }}
        run: |
          case "${{ matrix.kind }}" in
            linux)   bash scripts/package-linux.sh ;;
            macos)   bash scripts/package-macos.sh ;;
            windows) pwsh scripts/package-windows.ps1 ;;
          esac

      - name: 上传 GitHub Release
        shell: bash
        env:
          GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: |
          set -e
          if ! gh release view "${{ github.ref_name }}" >/dev/null 2>&1; then
            gh release create "${{ github.ref_name }}" \
              --title "ZzClawTerm ${{ github.ref_name }}" --generate-notes
          fi
          gh release upload "${{ github.ref_name }}" dist/ZzClawTerm-${{ github.ref_name }}-* --clobber
```

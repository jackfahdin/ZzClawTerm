# X11 设置与运行信息实现计划

> 使用 executing-plans 在当前会话逐项实现；本次不提交或推送。

**目标：** X 图标显示服务器状态和监听地址；启用开关下显示可复制的启动参数；增加剪贴板、PRIMARY、原生 OpenGL 和 DPI 设置。

**架构：** core 定义可序列化的启动选项；store 逐字段保存并保留未知 JSON 字段；transport 使用同一参数构造器启动及展示命令行，在后台查询 Windows 监听端口和网卡；desktop 使用缓存快照与现有 UI 包装器。

**技术栈：** Rust、GPUI、windows-sys。

## 1. 设置和启动参数

- [x] core `models/settings/x11.rs` 定义 `X11ServerOptions`，默认剪贴板、PRIMARY、WGL 开启，DPI 自动。
- [x] core `models/settings.rs` 增加带默认值的选项；store `storage/app_settings.rs` 逐字段加载/保存。
- [x] 在已有兼容性测试中验证旧数据默认值与新选项往返；transport `x11_server.rs` 验证禁用选项、DPI、认证文件含空格时的参数边界。
- [x] 所有启动路径传递选项，包括应用启动、设置开关和 SSH 按需启动；保持 `-auth`、`-noreset`、TCP 和多窗口行为。

## 2. 后台运行信息

- [x] transport `x11_server/listeners.rs` 查询 TCP 监听地址及适配器名称；过滤所属 PID（自管进程）和显示端口；只展示 IPv4，通配绑定展开活动 IPv4 网卡。
- [x] 纯映射测试覆盖环回绑定不会误报局域网地址、通配绑定展开、无监听结果。
- [x] transport 缓存运行状态、实际参数和启动错误，UI 读取缓存不等待启动锁；监视器定期刷新。
